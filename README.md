# 🧱 Jeu de Casse-Briques

Un petit jeu de **casse-briques** basé sur une balle, une raquette et plusieurs briques à détruire.

🎮 Dans ce projet, je vais vous montrer comment programmer un jeu de balle simple, avec une logique de déplacement, de collision et de destruction des briques.

## 🎯 Objectif

L'objectif de ce projet est de comprendre les bases de la création d'un petit jeu vidéo et de pratiquer la logique de programmation à travers un jeu simple et interactif.

## 🚀 Fonctionnalités

* ⚽ Déplacement de la balle
* 🧱 Destruction des briques
* 🎮 Contrôle de la raquette
* 💥 Gestion des collisions
* 🏆 Système de score
* 🔄 Rejouer après une partie

## 🛠️ Technologies utilisées

* HTML
* CSS
* JavaScript

## 📚 Ce que j'ai appris

Ce projet permet de travailler sur :

* La logique de jeu
* Les animations
* La détection des collisions
* Le déplacement des objets
* La gestion du score
* Les interactions avec le joueur
